# Spotify Popularity Analysis

## Overview
This project explores a dataset of 85,000 Spotify tracks to understand patterns in song popularity and how popularity relates to musical characteristics.

## Analysis
Using R, the project includes:
Exploratory data analysis
Descriptive statistics
Data visualization
Genre comparisons
Outlier analysis
Analysis of the relationship between danceability and popularity

## Tools
R
ggplot2

## Key Findings
Song popularity is unevenly distributed, with relatively few tracks reaching very high popularity.
Popularity varies across music genres.
Danceability shows a weak positive relationship with popularity.
Musical characteristics alone do not fully explain song popularity.
